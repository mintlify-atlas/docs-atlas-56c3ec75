## What is Horion?

Horion loads into Minecraft: Bedrock Edition via DLL injection and provides:

- **Module system** — 60+ toggleable modules organized into seven categories (Combat, Visual, Movement, Player, World, Misc, Custom)
- **In-game commands** — 30+ commands invoked with a configurable prefix (default `.`) directly in the chat box
- **JavaScript scripting** — Full Chakra-powered scripting engine to create new modules, listen to game events, and draw custom overlays
- **Config management** — Save and restore your module settings and keybinds as named JSON profiles
- **Click GUI** — Interactive in-game menu for toggling modules and adjusting their settings without typing commands
