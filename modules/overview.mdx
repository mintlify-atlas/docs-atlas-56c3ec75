Horion organizes its functionality into a **module system** — a collection of over 60 individual features grouped across seven categories: Combat, Movement, Visual, Player, World, Misc, and Custom. Every module can be independently enabled or disabled, assigned a keyboard shortcut, and tuned through its own set of configurable settings (floats, integers, booleans, and enum options). Whether you prefer clicking through a GUI or typing commands, Horion gives you full control over which modules are active and how they behave.

## Opening the ClickGUI

The ClickGUI is the primary interface for browsing, enabling, and configuring modules. Press **Insert** (default keybind) to open it. Inside the GUI, modules are listed by category. Left-click a module name to toggle it on or off. Right-click (or click the arrow/expand button) to reveal its settings panel where you can drag sliders, flip toggles, and choose enum options.

<Note>
  The ClickGUI itself is a module (`ClickGuiMod`) in the **Visual** category. Default keybind is **Insert**. You can rebind it just like any other module using `.bind ClickGuiMod <key>`.
</Note>

## Chat Commands

You can manage modules entirely from the in-game chat without touching the GUI:

| Command | Description |
|---|---|
| `.toggle <modulename>` | Enable or disable a module by name |
| `.bind <modulename> <key>` | Assign a keyboard shortcut to a module |
| `.bind <modulename> none` | Remove a module's keybind |

**Examples:**
```
.toggle Killaura
.bind Fly F
.bind Speed NUMPAD2
```

Module names are not case-sensitive. Use the name exactly as it appears in the ClickGUI (e.g., `Killaura`, `CrystalAura`, `FullBright`).

## Setting Types

Each module exposes zero or more settings. Settings come in four types:

| Type | Description | Example |
|---|---|---|
| `float` | Decimal number within a min/max range | `range = 4.0` (min 3, max 8) |
| `int` | Integer within a min/max range | `delay = 0` (min 0, max 20) |
| `bool` | True/false toggle | `multiaura = true` |
| `enum` | Selection from a named list of options | `mode = Fly \| CubeGlide` |

Settings persist between sessions via Horion's config system and are saved and loaded automatically.
