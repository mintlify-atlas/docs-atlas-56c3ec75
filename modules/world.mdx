Horion's World category contains modules that interact directly with the game world — breaking or placing blocks en masse, extending your block reach, and navigating the terrain automatically. Scaffold and Tower place blocks beneath or below you, while Nuker and InstaBreak focus on rapid destruction. The FollowPathModule provides automated traversal.

<Warning>
  World manipulation modules can cause grief or violations of server rules. Block-breaking modules like Nuker and InstaBreak are detectable by most anticheats. Use responsibly.
</Warning>

---

## Nuker

Rapidly breaks all solid blocks within a configurable radius around your character every tick.

**Tooltip:** *"Break multiple blocks at once"* · Default keybind: **Numpad 5**

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `radius` | int | 4 | 1 – 10 | Block-breaking radius in all three axes |
| `veinminer` | bool | false | — | Follow connected blocks of the same type (vein mining) |
| `auto destroy` | bool | true | — | Automatically break blocks each tick while enabled |

<Warning>
  Nuker breaks every solid block within the radius indiscriminately when `auto destroy` is on. Ensure you are not standing over important structures.
</Warning>

---

## InstaBreak

Bypasses block-breaking progress entirely, destroying the targeted block the moment you start breaking it.

**Tooltip:** *"Break any block instantly"* · Default keybind: **Numpad 4** · No configurable settings.

---

## Scaffold

Automatically places a block beneath your feet every tick as you walk, bridging gaps and preventing falls.

**Tooltip:** *"Automatically build blocks beneath you"* · Default keybind: **Numpad 1**

| Setting | Type | Default | Description |
|---|---|---|---|
| `Spoof` | bool | false | Silently switch to a block item without a visible hand animation |
| `Staircase Mode` | bool | false | Build a descending staircase instead of a flat bridge |

<Note>
  Requires at least one placeable block in your hotbar.
</Note>

---

## Tower

Rapidly builds a vertical tower by placing blocks below you on each jump, propelling you upward.

**Tooltip:** *"Like scaffold, but vertically and a lot faster"*

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `motion` | float | 0.5 | 0.3 – 1.0 | Upward velocity applied per placement cycle |

---

## FollowPathModule

Records or receives a path and automatically walks your character along it using Horion's built-in pathfinding system.

**Tooltip:** *"Follows joe paths"* · No configurable settings exposed via the settings API. Path data is managed programmatically.

<Note>
  FollowPathModule is categorized under **Movement** in the source (`Category::MOVEMENT`). It integrates with Horion's internal `JoePathFinder` and `JoeMovementController` systems and is primarily used via scripting or API calls.
</Note>
