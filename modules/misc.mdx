Horion's Misc category is a catch-all for modules that don't fit cleanly into combat, movement, visual, or player utility. It includes packet-level tools (Blink, PacketLogger, NoPacket), server crash exploits (Crasher, NoPaintingCrash), chat automation (Spammer), cosmetic tricks (Derp), health regen (Godmode), tick speed manipulation (Timer), quality-of-life tweaks (VanillaPlus), and movement utilities like Freecam and Teleport.

<Warning>
  Modules such as Crasher and NoPaintingCrash involve crash-inducing packet exploits. Using them to intentionally crash servers or other players is likely to result in permanent bans and may violate the terms of service of any server you are connected to. Use these modules only in controlled, private environments.
</Warning>

## Blink

Buffers all outgoing movement packets while enabled, then releases them all at once when disabled — effectively making your player appear frozen on the server until you "blink" back.

**Tooltip:** *"Stops you from sending packets and then sends them in a bunch"* · No configurable settings. Packet holders are flushed on disable.

<Tip>
  Blink is useful for rubber-banding to a previous server-side position, or for temporarily desynchronizing your client and server positions.
</Tip>

---

## PacketLogger

Logs every outgoing packet sent from your client to the server, printing the packet type to the in-game chat for debugging and analysis.

**Tooltip:** *"Logging Packets !"* · No configurable settings. Hooks `onSendPacket` and logs each packet type name.

---

## NoPacket

Blocks all outgoing `InventoryTransaction` packets from being sent to the server.

**Tooltip:** *"Prevents you from sending InventoryTransaction packets"* · Default keybind: **Numpad 7** · No configurable settings.

<Warning>
  Enabling NoPacket will prevent inventory interactions from being registered server-side. Most servers will eventually kick you after a timeout.
</Warning>

---

## Crasher

Sends a sequence of malformed or exploit packets designed to crash or heavily lag the target server.

**Tooltip:** *"Crash Realms Servers"* · No configurable settings. Runs on `onEnable`, `onTick`, and intercepts `onSendPacket`.

<Warning>
  Using Crasher against public or private servers without explicit permission is illegal under many jurisdictions and violates virtually all server terms of service. This module is documented for completeness only.
</Warning>

---

## NoPaintingCrash

Protects your client from a crash exploit that sends malformed painting entity packets, which would otherwise cause a native crash.

**Tooltip:** *"Fix Painting crash when using mob spawner !"* · No configurable settings. Passively intercepts painting-related packets.

---

## Spammer

Automatically sends a configurable chat message to the server at a regular interval.

**Tooltip:** *"Spams a message in a specified delay"*

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `delay` | int | 2 | 1 – 10 | Time between messages in seconds (multiplied by 20 ticks) |
| `length` | int | 8 | 1 – 60 | Length of the random suffix appended when bypass is enabled |
| `bypass` | bool | true | — | Append a random string to each message to bypass duplicate-message filters |

The default message is:
```
Horion - the best minecraft bedrock utility mod - horion.download
```

Use the `.spammer` command or the ClickGUI to change the message text.

---

## Derp

Rapidly alternates your head rotation in erratic patterns, creating a disorienting visual effect for observers and sometimes confusing anticheat rotation checks.

**Tooltip:** *"lol you stupid"*

| Setting | Type | Default | Description |
|---|---|---|---|
| `ihaveastroke` | bool | false | Use a more extreme, stroke-like rotation pattern |
| `packet mode` | bool | false | Apply rotations via sent packets instead of local view angle changes |

---

## Godmode

Regenerates your health so rapidly that you effectively cannot die — achieved by repeatedly sending health regeneration packets.

**Tooltip:** *"Regen health so fast you won't die"*

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `regen delay` | int | 5 | 1 – 20 | Ticks between regeneration pulses |
| `regen value` | int | 5 | 1 – 20 | Amount of health restored per pulse (in half-hearts) |

---

## Timer

Overrides the game's tick rate, causing the client to run faster or slower than normal.

**Tooltip:** *"Increase the ticks per second"*

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `ticks per second` | int | 50 | 0 – 500 | Number of game ticks per second (vanilla = 20) |

---

## VanillaPlus

Applies small quality-of-life tweaks to the default Minecraft experience.

**Tooltip:** *"Tweaks the minecraft experience"*

| Setting | Type | Default | Description |
|---|---|---|---|
| `Fast Item Lerp` | bool | true | Speed up the item pick-up animation for flying items |

---

## AntiImmobile

Prevents the server from flagging your client as immobile or idle, keeping movement packets flowing normally.

**Tooltip:** *"Disables immobile flag set by some servers to prevent you from moving"* · No configurable settings.

---

## EditionFaker

Spoofs the Minecraft edition reported to the server, making your Bedrock client appear as a different device.

**Tooltip:** *"Fakes your device to android"* · No configurable settings exposed to the GUI. Edition is returned internally via `getFakedEdition()`.

---

## Freecam

Detaches your camera and lets you fly it freely around the world while your character remains stationary on the server.

**Tooltip:** *"Move your cam without moving the player"* · Default keybind: **V**

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `Speed` | float | 0.325 | 0.50 – 1.25 | Camera flight speed |

---

## Teleport

Teleports your character to a targeted block by clicking on it, using movement packet injection.

**Tooltip:** *"Click a block to teleport to it"*

| Setting | Type | Default | Description |
|---|---|---|---|
| `Only Hand` | bool | false | Require a specific item in hand to activate |
| `Push` | bool | false | Use push-packet bypass method |

---

## Fucker

Automatically destroys specific types of interactable blocks (beds, eggs, cakes, treasures, chests, barrels) within range each tick. Commonly used in BedWars to destroy enemy beds.

**Tooltip:** *"Destroys certain blocks around you"* · Default keybind: **Numpad 9**

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `Range` | int | 5 | 1 – 10 | Scan radius in blocks |
| `Beds` | bool | true | — | Destroy bed blocks |
| `Eggs` | bool | true | — | Destroy dragon eggs |
| `Cakes` | bool | true | — | Destroy cake blocks |
| `Treasures` | bool | true | — | Destroy treasure/loot blocks |
| `Chests` | bool | false | — | Destroy chest blocks |
| `Barrels` | bool | false | — | Destroy barrel blocks |

---

## ClickGuiMod

The module that renders and manages the Horion ClickGUI overlay.

**Tooltip:** *"The clickgui - toggle everything by just clicking on it!"* · Default keybind: **Insert**

| Setting | Type | Default | Description |
|---|---|---|---|
| `Show Tooltips` | bool | true | Display module description tooltips in the GUI |

Press **Insert** (default) to open the ClickGUI. Rebind with:
```
.bind ClickGuiMod <key>
```

<Note>
  ClickGuiMod is categorized under **Visual** in the source (`Category::VISUAL`). It is listed here because it is the central control panel for all modules in every category.
</Note>
