Horion ships with a built-in command system that lets you control every part of the client without ever leaving Minecraft's chat box. Commands are fast, tab-friendly, and cover everything from toggling modules and managing configs to teleporting across the map and manipulating inventory items — all without requiring server-side operator permissions.

## Opening the Chat

Press **T** (or whatever key you have bound to "Open Chat") to open Minecraft's chat input box. Type your command and press **Enter** to execute it. The input is consumed by Horion before it reaches the server, so your commands never appear in public chat.

<Tip>
  You can also open chat with **/** — Horion intercepts the input regardless of which key you use to open it, as long as the message starts with the configured prefix.
</Tip>

## The Command Prefix

Every Horion command must begin with the **command prefix**. The default prefix is a period (`.`). For example, to list all modules you would type:

```
.modules
```

### Changing the Prefix

Use `.setprefix` to switch to any single character. The change persists across sessions (it is saved with your config).

```
.setprefix !
```

After running the above, all commands must start with `!` instead of `.`.

<Warning>
  If you change the prefix to a character that Minecraft also uses (such as `/`), Minecraft may intercept the input before Horion sees it. Stick to characters like `.`, `!`, `,`, or `#`.
</Warning>

## Getting Help In-Game

Run `.help` with no arguments to print every registered command along with its one-line description:

```
.help
```

To see the usage string for a specific command, pass its name as the first argument:

```
.help bind
.help tp
.help enchant
```

The usage string shows the expected arguments in angle-bracket (`<required>`) and square-bracket (`[optional]`) notation.

## Using Aliases

Most commands register one or more shorter aliases that work identically to the full command name. For example, these three lines do exactly the same thing:

```
.toggle killaura
.t killaura
```

Aliases are always lowercase. Use `.help` to see which alias belongs to which command.

## Passing Arguments

Arguments are separated by **spaces** and typed directly after the command name. The first token after the prefix is always the command name; everything after that is an argument indexed from 1.

```
.bind killaura r
.tp 100 64 -200
.give diamond_sword 1
```

Some commands accept a variable number of arguments — optional ones are shown in square brackets in the usage string. If a required argument is missing, Horion will print a usage error in chat.

<Note>
  Multi-word string arguments (such as `.say` or `.spammer message`) are assembled by joining all remaining tokens with spaces, so you do not need quotes around phrases.
</Note>

## Quick-Start Examples

```
.help                          # list all commands
.modules                       # list all modules
.toggle killaura               # toggle KillAura on/off
.bind sprint caps              # bind Sprint to Caps Lock
.tp 0 64 0                     # teleport to world origin
.coords                        # print current position
.config save                   # save current config
.panic                         # disable every module at once
```
